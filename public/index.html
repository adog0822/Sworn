How it works

        
    
          
  1. Listen. A Bolna voice agent calls the person who runs a control, at quarter end or the moment something drifts.
    2. 
          
  2. Type. Each statement becomes a typed claim (kind, scope, systems, approver). Every framework is a rendering of that one claim.
    3. 
          
  3. Verify. Deterministic checks read the systems: IAM credential report, Okta, Linear, GitHub, AWS Config. A spoken claim is a hypothesis; the system is the test.
    4. 
          
  4. Render and seal. Templates write each audience's version from checked facts. Calls are sealed with Ed25519 on a hash-chained log. Signing proves the record wasn't altered; the checks are what make it true.
